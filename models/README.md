# Models for Multi-class Bi-Atrial Segmentation

This subfolder contains the implementation of deep learning models for multi-class bi-atrial segmentation, adapted from the [3D volumetric V-Net models](https://github.com/junqiangchen/VNetFamily) and some other sources.

More resources of the V-Net models:

1. [ShawnBIT/UNet-family](https://github.com/ShawnBIT/UNet-family)
2. [MIC-DKFZ/nnUNet](https://github.com/MIC-DKFZ/nnUNet)
